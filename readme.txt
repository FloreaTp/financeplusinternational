FINANCE PLUS INTERNATIONAL — V2 starter files

Files:
- index.html
- css/style.css
- js/script.js

How to use:
1. Back up your current V2 folder first.
2. Copy index.html to the project root.
3. Copy css/style.css into the existing css folder.
4. Copy js/script.js into the existing js folder.
5. Keep thankyou.html in the project root.
6. Open the folder in VS Code and run Live Server.

Important:
- The Formspree endpoint is preserved from the existing project.
- This is a front-end website, not a secure loan origination or customer-account system.
- Verify company statistics, contact details, legal status and all product claims before publication.
- The calculator is illustrative only and does not include fees.
